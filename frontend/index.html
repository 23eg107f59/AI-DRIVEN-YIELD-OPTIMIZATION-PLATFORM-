About the model

Understand what powers this project—and where its limits are.

PROJECT OBJECTIVE

Make the path from field inputs to model output visible.

Oilseed AI is a local demonstration of a complete machine-learning application: validate a scenario, transform the same features used in training, estimate yield, and keep a useful history.

R² describes regression fit relative to a mean-target baseline; it is not classification accuracy or a percent of predictions that are correct. MAE and RMSE are measured in kg/ha. MAPE is calculated only over non-zero actual yields. Every metric and test plot comes from held-out records.

DATASET

Development data, clearly labeled.

The included CSV contains hypothetical scenarios generated for software development. It is not a real agricultural dataset. Results and metrics from it only demonstrate that the application pipeline works.

Read dataset schema and source note ↗
ALGORITHM

Random Forest Regressor

A scikit-learn pipeline imputes missing data, one-hot encodes categories and trains a Random Forest. A grouped split keeps regions (or farm IDs when provided) separate between train and test.

scikit-learn · joblib · GroupShuffleSplit
PHOTO CREDITS

Images of real Indian agricultural places

Crop cards use local photographs with source links, creator credit and license information. Regional labels follow source metadata; unavailable state-specific imagery is not implied.

View image credits and licenses ↗
LIMITATIONS

Not a farm decision system.

The small synthetic dataset cannot capture regional soils, cultivars, pests, seasonal variation or management quality. Metrics are a code-path check, not real-world validation. More regionally representative real data, external testing and agronomist review are essential.

Experimental · not for agronomic decisions
