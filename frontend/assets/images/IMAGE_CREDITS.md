copies are provided so the interface does not rely on remote image hosting.
Source pages were checked for image descriptions and license metadata before
download. Each source title below links to the Commons file page. The crop
cards describe only the crop/location documented on that source page.

Images are displayed as supplied, with crop/position styling only. The
rapeseed card explicitly uses a related mustard-field photograph as a visual
analogy, not as a photograph of rapeseed. No verified state-specific soybean

found for this set; the interface names the locations actually recorded by
image contributors instead. Image credits and license information are also
